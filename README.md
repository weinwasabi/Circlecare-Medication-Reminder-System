# CircleCare

**Medication reminders and patient monitoring for community healthcare.**

CircleCare is a mobile application developed to support medication reminder and patient monitoring workflows for healthcare staff at the Teen Center, Municipal Health Office of Polomolok, Philippines.

Built with **React Native, Expo, and SQLite**.

[Portfolio](https://itslou.dev/) · [GitHub Repository](https://github.com/weinwasabi/Circlecare-Medication-Reminder-System)

## Overview

Keeping track of medication schedules and patient information is an important part of day-to-day healthcare work.

CircleCare explores how a mobile application can help organize these processes for doctors and nurses in a community healthcare setting.

## Project Scope

| Area | Purpose |
|---|---|
| Medication Reminders | Support medication scheduling and reminder workflows |
| Patient Monitoring | Support staff in tracking patient-related information |
| Healthcare Workflows | Provide an application designed around doctors' and nurses' needs |
| Local Storage | Use SQLite for on-device application data |

## Technology Stack

| Technology | Purpose |
|---|---|
| React Native | Cross-platform mobile development |
| Expo | React Native development framework and tooling |
| SQLite | Local database and data persistence |

## High-Level Architecture

The application is organized around three main areas:

1. **Mobile Interface** — React Native and Expo provide the mobile application experience.
2. **Application Logic** — Medication reminder and patient monitoring workflows.
3. **Data Layer** — SQLite provides local application data storage.

## Getting Started

### Prerequisites

- Node.js and npm
- Expo-compatible development environment
- Android emulator, iOS simulator, or compatible physical device

### Installation

Clone the repository:

`git clone https://github.com/weinwasabi/Circlecare-Medication-Reminder-System.git`

Navigate to the project:

`cd Circlecare-Medication-Reminder-System`

Install dependencies:

`npm install`

Start the development server:

`npx expo start`

These are standard Expo commands. The repository's package manager and native dependencies should be checked for any additional setup requirements.

## Project Background

CircleCare was developed during an IT internship at the **Teen Center, Municipal Health Office of Polomolok**.

The project provided an opportunity to apply mobile development skills in a real healthcare environment while learning about the workflows and responsibilities of healthcare professionals.

It reflects an interest in building practical software that helps organizations manage everyday processes.

## Privacy and Responsible Use

CircleCare involves healthcare-related workflows and requires responsible handling of sensitive information.

- Do not publish identifiable patient records or private databases.
- Use fictional or anonymized information for demonstrations.
- Evaluate data security, access control, and regulatory requirements before any production deployment.

CircleCare is an internship software project, not a clinically certified medical system.
